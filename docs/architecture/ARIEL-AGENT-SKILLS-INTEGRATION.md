# Ariel Agent Skills Integration

## Purpose

Define the boundary between Adaptive AI Orchestrator and the portable engineering skills maintained in `oliveiraariel/ariel-agent-skills`.

## Contract

`ariel-agent-skills/registry/skills.json` is a portable catalog whose fields map directly onto the orchestrator's `SkillProfile` domain object:

- `id` → `SkillId`
- `purpose`
- `capabilities`
- `inputs`
- `outputs`
- `dependencies`
- `compatible_agents`
- `compatible_models`
- `compatible_runtimes`
- `version`
- `evidence`

`infrastructure.skill_registry_loader.load_skill_profiles()` loads that registry from a local or materialized path. It does **not** fetch GitHub, install skills, or invoke runtimes. Those remain separate adapter/installation concerns.

## Selection flow

```text
Work Unit required_capabilities
          ↓
AgentSkillAnalysis
          ↓
SkillProfile candidates loaded from registry
          ↓
ResourceSelection
          ↓
agent + skill(s) + model + runtime
          ↓
ExecutionCoordinator / policy / claim / runtime
          ↓
independent evaluation + finalization
```

## Why the boundary is file-based

The orchestrator must not depend on a live GitHub repository or a particular agent harness. A registry can be vendored, mounted, downloaded by an external installer, or generated by another catalog service. The loader consumes only the stable manifest contract.

## Authority

The skill registry describes capabilities and compatibility; it does not grant execution authority. `ExecutionPolicy`, human-approval gates, Work Unit intent, runtime restrictions, dependency state, and independent evaluation remain authoritative orchestration concerns.

## Upstream influence

The Matt Pocock ecosystem influenced frontier scheduling, task-graph execution, context economy, independent review axes, and handoff discipline. Deprecated/person-specific/runtime-specific skills are not imported by identity. Reusable mechanisms are either implemented in the orchestrator or represented in the compact Ariel skill ecosystem.
