# Plan Domain — WU-007

Initial domain representation for the planned project state.

## Implemented

- `Plan`
- `PlanVersion`
- `PlanStatus`
- baseline reference
- Work Units
- dependencies
- priorities
- parallel groups
- gates
- basic lifecycle invariants
- domain tests

## Scope

This Work Unit does not calculate readiness, resolve dependency graphs,
construct plans, or determine execution order.

Those concerns remain for the subsequent planning Work Units.
